# Руководство по редактированию контента сайта

## Структура файлов контента

Все тексты на сайте хранятся в папке `/src/app/content/`:

```
src/app/content/
├── types.ts          # Типы данных (не редактировать)
├── index.ts          # Экспорты (не редактировать)
├── home.ts           # Контент главной страницы
├── vendai.ts         # Контент страницы ВендИИ
├── inventory.ts      # Контент страницы Инвентаризатор
├── contact.ts        # Контент страницы контактов
└── ...               # Другие страницы
```

## Как редактировать тексты

### 1. Откройте нужный файл контента

Например, чтобы изменить тексты на главной странице, откройте файл:
```
/src/app/content/home.ts
```

### 2. Найдите нужный раздел и измените текст

```typescript
export const homeContent: HomePageContent = {
  hero: {
    title: {
      highlight: "Системы компьютерного зрения и искусственного интеллекта",
      rest: "от российского разработчика"
    },
    description: "Ваш новый текст здесь...",
  }
};
```

### 3. Сохраните файл

После сохранения изменения автоматически применятся на сайте.

## Структура контента для разных типов страниц

### Главная страница (home.ts)

```typescript
{
  seo: {
    title: "...",           // Заголовок для поисковиков
    description: "...",     // Описание для поисковиков
    keywords: "..."         // Ключевые слова
  },
  hero: {
    badge: "...",           // Значок над заголовком
    title: {
      highlight: "...",     // Выделенная часть заголовка
      rest: "..."           // Остальная часть заголовка
    },
    description: "...",     // Описание под заголовком
    buttonPrimary: "...",   // Текст главной кнопки
    buttonSecondary: "..." // Текст второстепенной кнопки
  },
  features: [              // Список преимуществ
    {
      title: "...",
      description: "..."
    }
  ]
}
```

### Страницы продуктов (vendai.ts, inventory.ts и т.д.)

```typescript
{
  seo: {
    title: "...",
    description: "...",
    keywords: "..."
  },
  hero: {
    badge: "...",          // Значок над заголовком
    title: "...",          // Главный заголовок
    subtitle: "...",       // Подзаголовок (опционально)
    description: "...",    // Описание
    buttonText: "..."      // Текст кнопки
  },
  features: [              // Основные характеристики
    {
      title: "...",
      description: "..."
    }
  ],
  benefits: [              // Преимущества (опционально)
    {
      title: "...",
      description: "..."
    }
  ],
  cta: {                   // Призыв к действию внизу страницы
    title: "...",
    description: "...",
    buttonText: "..."
  }
}
```

### Страница контактов (contact.ts)

```typescript
{
  form: {
    nameLabel: "...",          // Подпись поля имени
    namePlaceholder: "...",    // Подсказка в поле имени
    emailLabel: "...",
    emailPlaceholder: "...",
    phoneLabel: "...",
    phonePlaceholder: "...",
    messageLabel: "...",
    messagePlaceholder: "...",
    consentText: "...",        // Текст согласия на обработку данных
    submitButton: "...",       // Текст кнопки отправки
    successTitle: "...",       // Заголовок при успешной отправке
    successMessage: "..."      // Сообщение при успешной отправке
  }
}
```

## Примеры частых изменений

### Изменить заголовок на главной странице

```typescript
// Файл: src/app/content/home.ts
hero: {
  title: {
    highlight: "Новый текст выделенной части",
    rest: "новый текст обычной части"
  }
}
```

### Изменить описание продукта

```typescript
// Файл: src/app/content/vendai.ts
hero: {
  description: "Новое описание вендингового автомата..."
}
```

### Добавить новое преимущество

```typescript
features: [
  {
    title: "Существующее преимущество 1",
    description: "Описание..."
  },
  {
    title: "Существующее преимущество 2",
    description: "Описание..."
  },
  // Добавляем новое:
  {
    title: "Новое преимущество",
    description: "Описание нового преимущества"
  }
]
```

### Изменить текст кнопки

```typescript
hero: {
  buttonText: "Новый текст кнопки"
}
```

## Создание файла контента для новой страницы

1. Создайте новый файл, например `src/app/content/newpage.ts`

2. Скопируйте шаблон:

```typescript
import { PageContent } from './types';

export const newpageContent: PageContent = {
  seo: {
    title: "Заголовок страницы для SEO",
    description: "Описание страницы для SEO",
    keywords: "ключевые, слова, через, запятую"
  },
  hero: {
    badge: "Значок",
    title: "Заголовок",
    description: "Описание",
    buttonText: "Текст кнопки"
  },
  features: [
    {
      title: "Характеристика 1",
      description: "Описание характеристики 1"
    }
  ],
  cta: {
    title: "Призыв к действию",
    description: "Описание призыва",
    buttonText: "Текст кнопки"
  }
};
```

3. Добавьте экспорт в `src/app/content/index.ts`:

```typescript
export { newpageContent } from './newpage';
```

## Важные замечания

⚠️ **Не изменяйте:**
- Файл `types.ts` - содержит определения структуры данных
- Файл `index.ts` - содержит только экспорты
- Названия полей (например, `title`, `description`) - только их значения

✅ **Можно изменять:**
- Любой текст внутри кавычек `"..."`
- Количество элементов в массивах `features`, `benefits`
- Добавлять или удалять опциональные разделы

💡 **Советы:**
- Используйте `\n\n` для разрыва параграфов в длинных текстах
- Сохраняйте кавычки и запятые при редактировании
- После изменений проверьте, что сайт правильно отображается
- Делайте резервные копии перед большими изменениями

## Применение контента в компоненте

Чтобы использовать контент в React-компоненте:

```typescript
import { vendaiContent } from '../content';

export function VendAI() {
  const { seo, hero, features } = vendaiContent;
  
  return (
    <>
      <SEO {...seo} />
      <h1>{hero.title}</h1>
      <p>{hero.description}</p>
    </>
  );
}
```
